# 一类 Helmholtz 问题稳定性的数值研究（英中对照·分片1：摘要、引言、模型问题与傅里叶分析）

体例：[EN] 原文（公式用字体安全 Unicode：Δ 拉普拉斯、∂/∂ν 法向导数、≤/≥、√），[中] 汉译。

## Abstract｜摘要

[EN] This paper concerns the stability of a class of Helmholtz problems in rectangular domains. A well-known application is the electromagnetic scattering from a rectangular cavity embedded in an infinite ground plane. Error analysis of numerical methods for cavity problems relies heavily on the stability estimates. However, it is extremely difficult to derive an optimal stability bound with explicit dependency on wave numbers. A high-order finite element approximation is proposed for calculating the stability bound. Numerical experiments show that the stability depends strongly on wave numbers in extreme cases and is almost independent of the wave numbers in an average sense. The numerical results also help to understand the stability of the multi-frequency inverse problems.

[中] 本文研究矩形域上一类 Helmholtz 问题的稳定性。著名应用是无限大接地平面上矩形腔体的电磁散射。腔体问题数值方法的误差分析高度依赖稳定性估计；然而，给出**显式依赖波数**的最优稳定性界极其困难。本文提出用高阶有限元逼近来计算稳定性界。数值实验表明：极端情形下稳定性强烈依赖波数，而在平均意义下几乎与波数无关。数值结果还有助于理解多频逆问题的稳定性。

## 1. Introduction｜引言

[EN] Numerical solution of Helmholtz type equations is one of the most challenging problems in scientific computing (electromagnetic scattering, optics, acoustics). Problems with large wave numbers — large "ka" numbers, k the wavenumber, a the domain diameter — are of significant interest; the main difficulty is the highly oscillatory nature of the fields. Many methods exist (FDM, FEM, BEM, DG, spectral, mode matching, hybrid), but error estimates with wave-number-explicit bounds have not been well done. The essential issue is the stability estimate with explicit k-dependence, which strongly depends on geometry and boundary conditions. Known results: Melenko's estimate for 2D impedance problems under special geometry; Cummings–Feng in 3D star-shaped domains; Hetmaniuk's O(1) bound for mixed/nonhomogeneous impedance; Shen–Wang O(1) (spectral Galerkin, annulus, impedance) and O(k^{1/3}) with exact transparent boundary; Chandler-Wilde–Monk uniform bound for starlike obstacles; O(k²) for unbounded rough surfaces via Fourier analysis. Convergence analyses: Melenk et al. hp-FEM (quasi-optimality if kh/p small, p ≥ O(log k), solution operator polynomially bounded in k); Feng–Wu IPDG optimal H¹ without mesh constraints.

[中] Helmholtz 型方程的数值求解是科学计算最具挑战性的问题之一（电磁散射、光学、声学）。大波数（大 ka 数）情形最受关注，核心困难在于场的强振荡性。方法众多（有限差分、有限元、边界元、间断伽辽金、谱方法、模式匹配、混合方法），但**波数显式**的误差估计一直做得不好。关键问题是稳定性估计的显式 k 依赖，而它强烈依赖区域几何与边界条件。已知结果：Melenko 在特殊几何下对二维阻抗问题的估计；Cummings–Feng 在三维星形域的同类估计；Hetmaniuk 对混合/非齐次阻抗条件的 O(1) 一致界；Shen–Wang 对环形域谱 Galerkin 的 O(1) 界与精确透明边界下的 O(k^{1/3})；Chandler-Wilde–Monk 对星形障碍的一致界；粗糙表面分布源的 O(k²)（连续 Fourier 分析）。收敛性分析：Melenk 等的 hp-FEM（kh/p 足够小、p ≥ O(log k)、解算子关于 k 多项式有界时拟最优）；Feng–Wu 的 IPDG 无网格约束的最优 H¹ 估计。

[EN] This paper considers Helmholtz problems in rectangular domains; the well-known application is EM scattering from a large open cavity embedded in an infinite ground plane (industrial/military significance: RCS reduction). Since the upper half-space is homogeneous, a transparent (nonlocal) boundary condition on the aperture (via Green's function / Fourier transform) reduces the problem to a bounded cavity with nonlocal transparent BC (hypersingular kernel for TM) — more complicated than classical interior/exterior Helmholtz problems. Existence/uniqueness in [2]; many numerical methods in 20 years. Error analysis relies on stability estimates with explicit k for both distributed and incident source scattering; recent bounds: O(k^{15/4}(log k)^{1/4}) [12] (incident), O(k²) and O(k^{7/4}) [30]. Pollution effect [4] may seriously influence accuracy (1D model: k²h ≪ 1). Using the arbitrary high-order tensor-product FEM [18], a numerical study shows: worst cases arise only for a discrete set of wave numbers; otherwise the energy-norm stability is almost a constant and pollution is not serious. Related: multi-frequency inverse source problems (non-uniqueness + ill-posedness at fixed frequency, overcome by multiple frequencies); since solving the inverse problem requires sequences of direct problems, the finding "stability is bad only at some discrete frequencies; good on average" helps understand multi-frequency inverse problems.

[中] 本文考虑矩形域上的 Helmholtz 问题；典型应用是接地平面上大开口腔体的电磁散射（工业/军事意义重大：RCS 缩减）。上半空间均匀，可用格林函数/傅里叶变换在口面引入透明（非局部）边界条件，把无穷域问题化为带非局部透明边界（TM 情形具超奇异核）的有界腔体问题——比经典内域/外域 Helmholtz 问题更复杂。解的存在唯一性见 [2]；20 年来数值方法众多。其误差分析依赖**分布源**与**入射源**两类散射问题的波数显式稳定性估计；已有界：入射源 O(k^{15/4}(log k)^{1/4}) [12]、分布源 O(k²) 与入射源 O(k^{7/4}) [30]。污染效应 [4] 可能严重影响精度（一维模型要求 k²h ≪ 1，实际难以满足）。本文借助任意高阶张量积 FEM [18] 做数值研究，启发式地发现：**最坏情形只发生在一组离散波数上；其余情形能量范数稳定性几乎为常数、污染不严重**。相关背景：多频逆源问题（固定频率下不唯一+不适定，多频数据可克服）需要反复解正问题——"稳定性只在个别离散频率差、平均意义良好"这一发现有助于理解多频逆问题的稳定性。

## 2. Model problems｜模型问题

[EN] Time-harmonic plane wave (E^i, H^i) incident on a cavity in an infinite ground plane (PEC walls). TM polarization: u = E^z, k = ω√(εμ); Helmholtz equation Δu + k²u = 0 in Ω ∪ U⁺_b, u = 0 on Γ_C ∪ S, Sommerfeld condition at infinity ⟨公式(2.2)⟩. Transparent BC on the aperture reduces to the bounded problem ⟨公式(2.3)：Δu + k²u = 0 in Ω; u = 0 on S; ∂νu = T(u) + g on Γ⟩, where ⟨公式(2.4)：T(u) = (ik/2) ∫₀^a (1/|x−x′|) H¹₁(k|x−x′|) u(x′,b) dx′⟩ is a hypersingular Hadamard finite-part integral, g(x) = −2iβe^{iαx}. For simplicity Ω = (0,1)×(0,b); the general model ⟨公式(2.5)：Δu + k²u = f⟩ with f ∈ L²(Ω), g ∈ L²(Γ). Two cases: T(u) = iku, or the exact nonlocal operator (2.4). Unique solution if Im(∫_Γ T(u)ū) ≥ 0 and Im(k) ≥ 0; countable resonant frequencies where f = g = 0 has nontrivial solutions. Model (2.5) decouples into distributed source ⟨公式(2.6)⟩ and incident source ⟨公式(2.7)⟩ problems. Appendix A: for (2.6) with T = iku, ‖∇u‖ + k‖u‖ ≲ k²b²‖f‖ (energy method). Fourier series gives for (2.7) with T = iku: ‖∇u‖ + k‖u‖ ≲ kb^{3/2}‖g‖. Sharp example ⟨公式(2.8)：k² = (m² + 1/b²)π², g = −(π/b)sin(mπx), u = sin(mπx)sin(πy/b)⟩ attains √2/π · k b^{3/2}‖g‖. Literature bounds: distributed O(k²) [13]; incident O(k^{15/4}(log k)^{1/4}) [12]; exact T: O(k²‖f‖ + k‖g‖_{H^{1/2}} + k^{7/4}‖g‖) [30]. Numerically, for the cavity: ‖∇u‖ + k‖u‖ ≲ k^{3/2}‖f‖ + k‖g‖. Comparison: simplified model ⟨公式(2.9)⟩ has O(1) stability [24] — the nonlocal operator T makes the cavity problem much harder.

[中] 时谐平面波入射到接地平面（理想电导体壁）上的腔体。TM 极化下 u = E^z、k = ω√(εμ)，归结为 Ω ∪ U⁺_b 上的 Helmholtz 方程 + PEC 边界 + Sommerfeld 条件 ⟨公式(2.2)⟩。口面上的透明边界条件把问题化为有界域问题 ⟨公式(2.3)⟩，其中 T 是 Hadamard 有限部分意义下的**超奇异积分算子** ⟨公式(2.4)，含第一类 Hankel 函数⟩，g(x) = −2iβe^{iαx}。为简单设 Ω = (0,1)×(0,b)；一般模型 ⟨公式(2.5)⟩。两种情形：T(u) = iku（简化阻抗式）或精确非局部算子 (2.4)。当 Im(∫_Γ T(u)ū) ≥ 0 且 Im(k) ≥ 0 时解唯一；f = g = 0 有非平凡解的可数 k 值即**谐振频率**。模型 (2.5) 解耦为分布源问题 ⟨公式(2.6)⟩ 与入射源问题 ⟨公式(2.7)⟩。附录 A 用能量法证明 (2.6)（T = iku）：‖∇u‖ + k‖u‖ ≲ k²b²‖f‖；傅里叶级数给出 (2.7)：‖∇u‖ + k‖u‖ ≲ kb^{3/2}‖g‖。尖锐算例 ⟨公式(2.8)⟩ 表明该界达到 √2/π · k b^{3/2}‖g‖（最优）。文献已有界：分布源 O(k²) [13]；入射源 O(k^{15/4}(log k)^{1/4}) [12]；精确 T：O(k²‖f‖ + k‖g‖_{H^{1/2}} + k^{7/4}‖g‖) [30]。本文数值结果显示腔体问题 ‖∇u‖ + k‖u‖ ≲ k^{3/2}‖f‖ + k‖g‖。对比：简化模型 ⟨公式(2.9)⟩ 有 O(1) 稳定性 [24]——**非局部算子 T 正是腔体问题稳定性困难的根源**。

Mode energies ⟨公式(3.3)-(3.6)⟩ and coefficients give ‖∇u‖² + k²‖u‖² = ½(Σ η(n)|g_n|² + Σ μ(n)|g_n|²) (+resonance term if k̃ ∈ N), with explicit η(n), μ(n). Therefore ⟨公式(3.7)：‖∇u‖ + k‖u‖ ≤ β(k)‖g‖⟩ with explicit β(k) = √(2C(k,b)), C(k,b) = max{...}, yielding ‖∇u‖ + k‖u‖ ≲ kb^{3/2}‖g‖.

[中] 矩形域使 (2.7)（T = iku）可用傅里叶级数显式求解 ⟨公式(3.1)(3.2)⟩：n < k̃ = k/π 的传播模态为 sin(√(k²−n²π²)y)，n > k̃ 的倏逝模态为 sinh(√(n²π²−k²)y)；若 k̃ ∈ N 还会出现共振项 a_k̃·y·sin(kx)。逐模态计算能量 ⟨公式(3.3)-(3.6)⟩ 得 ‖∇u‖² + k²‖u‖² = ½(Σ η(n)|g_n|² + Σ μ(n)|g_n|²)（共振情形多一项），其中 η(n)、μ(n) 显式。由 sinh(2s)/(2s·cosh²s) < 1 单调递减得 max μ(n) = μ(⌊k̃⌋+1) < b；再用辅助函数 φ(s) 在 [0, π/4] 上 ≤ 8/3、在 (π/4, kb) 上 ≤ 32k²b²/π² 界住 max η(n)。于是得到显式稳定常数 ⟨公式(3.7)：‖∇u‖ + k‖u‖ ≤ β(k)‖g‖，β(k) = √(2C(k,b))⟩，并证明 ‖∇u‖ + k‖u‖ ≲ kb^{3/2}‖g‖。图 3 画出 b = 1、k ∈ [150, 200] 时 β(k) 的曲线——大部分 k 处接近常数，仅在特定离散 k 处出现尖峰。
