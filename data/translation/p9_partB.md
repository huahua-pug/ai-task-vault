# 英中对照·分片2：非匹配网格实验、波导可扩展性实验与结论

## 3.2 MMS with non-matching meshes｜非匹配网格的 MMS 实验

[EN] Same geometry, non-matching interface mesh; three setups: (i) second-order hexahedra (Ω₁) vs tetrahedra (Ω₂) — triangle/quadrilateral mismatch; (ii) hexahedra → triangular prisms in Ω₁ (similar plane-wave approximation in both subdomains); (iii) third-order prisms in Ω₁. Pointwise error fields ⟨Figs. 7-9⟩: no particular hotspots inside subdomains; an error increase appears in the vicinity of the interface Γ₁₁₂ on the Ω₁₂ side. Table 4 (with vs without DDM): a slight error increment in both domains — expected, since the exact MMS data is not imposed on the interface but the approximation from the neighbor domain. Second experiment: similar approximations in both subdomains → smaller increment; no hotspots on the interface; the FE shape plays no role (DDM points are shape-independent). Third experiment: error in Ω₁₂ lower than experiments 1-2 (better approximation from the prisms), but the increment in Ω₁₁ is much higher due to the worse approximation of the fields in Ω₁₂ — again localized near the interface without affecting the interior. General conclusion: the error in a subdomain is lower when the neighbor's approximation is better (same effect, attenuated, for the curl).

[中] 同一几何、界面网格不匹配；三种设置：(i) 二阶六面体（Ω₁）对二阶四面体（Ω₂）——三角形/四边形错配；(ii) Ω₁ 改为三棱柱（两子域对平面波的逼近相近）；(iii) Ω₁ 升为三阶棱柱。逐点误差场 ⟨图7-9⟩：子域内部无特殊热点；误差增大出现在界面 Γ₁₁₂ 附近的 Ω₁₂ 一侧。表 4（有无 DDM 对照）：两个域误差都有轻微增大——符合预期，因为界面上施加的不是精确的 MMS 数据而是邻居域的逼近。第二实验：两子域对平面波逼近相近 → 增量更小；界面无热点；**单元形状对误差无影响**（DDM 点技术与形状无关）。第三实验：Ω₁₂ 误差低于前两实验（棱柱逼近更好），但 Ω₁₁ 误差增量更大（因 Ω₁₂ 场逼近更差）——同样只局限于界面附近、不影响域内部。总体结论：**某子域的误差取决于邻居域逼近的好坏**（旋度的误差同样存在此效应但较弱）。

[EN] Eigenspectra with non-conformality: the braces within the circle are less defined [28], but SOTC still converges faster — with ε = 10⁻¹², 306 (FOTC) vs 186 (SOTC) iterations.

[中] 非协调性下的特征谱：圆内的"花括号"结构变得不那么分明 [28]，但 SOTC 收敛仍更快——ε = 10⁻¹² 时 FOTC 306 次、SOTC 186 次迭代。

## 3.3 WR-90 waveguide｜WR-90 波导实验

[EN] WR-90 waveguide at 10 GHz; demanding because the subdomain division parallel to the wave ports introduces a mesh discontinuity in the propagation direction. Prior work [15, §5.1]: convergence rate 3.8 (theory 4) with second-order tetrahedra over six subdomains; iterations increase with the number of subdomains unless special techniques (GPWD, addressing almost-evanescent modes near interfaces) are applied. (a) Scalability with the number of subdomains: waveguide sliced into 0.5λ sections; two interleaved mesh densities (prisms + tetrahedra); three interface geometries (triangles-triangles, rectangles-rectangles, hybrid triangles-rectangles); transmission error ⟨公式(21)：ς_s = |s21,DDM − s21,ref|/|s21,ref|·100⟩ with ε = 10⁻⁶. Results ⟨Figs. 13-14⟩: the error grows linearly with a low slope with the number of subdomains (bounded by a reasonable value — note the axis scale); FE shape irrelevant; raising the order to p = 3 gives the same trend with much lower error; iterations increase with the number of subdomains (also observed in [15]) but are reduced for third-order basis functions (better mode approximation). (b) Aspect ratio on the interface: three scenarios (tetrahedra size mismatch; prisms with changed middle-subdomain size → quadrilateral mismatch; prism-tetrahedron mismatch) ⟨Fig. 15⟩. Results ⟨Figs. 16-17⟩: the aspect ratio does not significantly affect the error, with aspect ratios as demanding as 16 — likely because the mode approximation on the interface is set by the coarser mesh; the three mismatch geometries yield similar results; p = 3 reduces the error further; iteration counts differ but remain reasonable. Encouraging for independent adaptive refinement per subdomain.

[中] WR-90 波导、10 GHz；子域分割平行于波端口 → **在传播方向上引入网格间断**，属于苛刻场景。先前工作 [15 §5.1]：六子域二阶四面体的收敛率 3.8（理论 4）；不加特殊技术（GPWD 处理界面附近近倏逝模）时迭代数随子域数增长。(a) **子域数可扩展性**：波导按 0.5λ 切片；两种网格密度交错（棱柱 + 四面体）；三种界面几何（三角-三角、四边-四边、混合三角-四边）；传输误差 ⟨公式(21)⟩、ε = 10⁻⁶。结果 ⟨图13-14⟩：误差随子域数**线性增长且斜率低**（增幅有界、纵轴尺度可见其量级合理）；单元形状不影响结论；阶数升至 p = 3 时趋势相同但误差低得多；迭代数随子域数增长（[15] 中亦观察到）但三阶基函数使迭代数下降（模态逼近更好）。(b) **界面长宽比**：三种错配场景（四面体尺寸错配；三棱柱中间子域变尺寸 → 四边形错配；棱柱-四面体错配）⟨图15⟩。结果 ⟨图16-17⟩：**长宽比高达 16 也不显著影响误差**——可能因为界面上的模式逼近由较粗一侧网格决定；三种错配几何结果相似；p = 3 进一步降误差；迭代数有差异但数值合理。这些结果为"各子域独立自适应加密"铺路。

## 4. Conclusions｜第4章 结论

[EN] A study of the accuracy of non-conformal, non-overlapping DDM applied to a FEM code: second-order transmission conditions and DDM points to ease the connection on non-matching interfaces. Results with different shapes (tetrahedra, hexahedra, prisms): the approximation error is not affected by the shape choice. Non-matching meshes with smooth excitations: the error increase in one subdomain propagates to the vicinity of the neighbor subdomain without compromising the whole-problem accuracy. WR-90 propagation problem: error increases within reasonable limits with the number of discontinuities in the propagation direction; the aspect ratio on the interface leaves the error approximately unchanged. Promising: the loss of accuracy is only present with a mesh mismatch on the interface, independently of the FE shape and the order — paving the way for: using different FE shapes to adapt to the geometry; introducing hp adaptivity per subdomain with significant computational savings (future work).

[中] 本文研究了应用于 FEM 代码的非协调、不重叠 DDM 的解精度：采用二阶传输条件与"DDM 点"技术连接非匹配界面。不同单元形状（四面体、六面体、三棱柱）的结果表明：**形状选择不影响逼近误差**。光滑激励下非匹配网格的实验：某子域的误差增量传播到邻居子域附近区域，但不影响整体问题的逼近精度。WR-90 传播问题：误差随传播方向间断数目在合理限度内增长；**界面长宽比基本不改变误差**。结论令人鼓舞：精度损失只在界面网格失配时出现、与单元形状和基函数阶数无关——这为两点铺路：①用不同单元形状适配几何；②按子域独立实施 hp 自适应以显著节省计算资源（未来工作）。
